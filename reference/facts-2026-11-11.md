# Verified facts for the bootcamp (checked 2026-11-11 against code.claude.com/docs/en and platform.claude.com/docs; Claude Code 2.1.322)

Condensed from three doc lookups. "ND" = not documented on the pages read; verify by running it. Subscription-plan facts (5-hour and weekly windows, what counts, overage) are NOT verified yet.

## Tokens, caching, pricing (API)
- Usage fields: `input_tokens` (only tokens after the last cache breakpoint), `cache_creation_input_tokens`, `cache_read_input_tokens`, `output_tokens`; `cache_creation.ephemeral_5m_input_tokens` + `ephemeral_1h_input_tokens` = cache creation. Total input = read + creation + input.
- Cache write: 1.25x base input (5-minute TTL, the default) or 2x (1-hour, `"cache_control":{"type":"ephemeral","ttl":"1h"}`). Cache read: 0.1x; 0.05x on Opus 5.5 and Sonnet 5.5; 0.025x on Fable/Mythos 5.1 and 5.2. A hit refreshes the TTL free. Max 4 breakpoints. Minimum cacheable prompt 512 tokens on current models (older: 1,024 to 4,096).
- Prefix order: tools, system, messages. A tool-definition change invalidates all three; web-search/citations toggle or speed change invalidates system and messages; tool choice or images invalidate messages; thinking/effort changes are model-specific.
- Prices per million tokens, input/output: Opus 5.5 $4/$20; Sonnet 5.5 $2/$10; Haiku 5.5 $0.10/$0.50 for prompts up to 100k tokens and $0.50/$2.50 above (prompt length counts cache reads and writes); Fable/Mythos 5.2 $8/$40. Output is 5x input on every current model. Batch API: 50% off input and output. No long-context premium except the Haiku 5.5 step.
- Context: 1M window on current models (default in Claude Code for Fable, Sonnet 5+, Haiku 5.5, Opus 4.7+); max output 128k. Thinking tokens are billed as output and count toward the window; prior thinking blocks are kept on current models. Token counting endpoint is free and an estimate.
- Costs page guidance: `/clear` between tasks and custom `/compact` instructions; Sonnet for most work, `model: haiku` for simple subagents; cut MCP overhead; move CLAUDE.md detail into skills (CLAUDE.md under 200 lines); lower `/effort`. Docs figure: about $13 per developer per active day.

## Context management in Claude Code
- `/context [all]` live breakdown by category (names ND). `/compact [instructions]`. Auto-compact at the context limit by default (about 967K on 1M models); set with `/autocompact`, `autoCompactWindow` or `CLAUDE_CODE_AUTO_COMPACT_WINDOW` (100K to 1M). `/clear [name]`. `/usage` shows session cost, plan limits, per-model tokens and a `Prompt cache (main)` line; `/cost` and `/stats` are aliases.
- MCP tool search is on by default: tool definitions are deferred, only names and server instructions load. `ENABLE_TOOL_SEARCH` = unset/true, `false`, `auto` (upfront while under 10% of the window), `auto:N`.
- First 200 lines or 25KB of MEMORY.md load at session start.

## Skills and commands
- Skill = `<name>/SKILL.md` in `~/.claude/skills/`, `.claude/skills/`, or a plugin's `skills/`. All frontmatter optional; `description` recommended. Fields: `name`, `description`, `when_to_use`, `argument-hint`, `arguments`, `disable-model-invocation`, `user-invocable`, `allowed-tools`, `disallowed-tools`, `model`, `effort`, `context: fork`, `agent`, `background`, `hooks`, `paths`, `shell` (bash|powershell).
- Loading: description always in context, body on invocation; with `disable-model-invocation: true` the description is not in context. Keep SKILL.md under 500 lines. Listing budget: 1% of the context window; each description + when_to_use capped at 1,536 chars; descriptions dropped least-used first (`skillListingBudgetFraction`, `SLASH_COMMAND_TOOL_CHAR_BUDGET`). After compaction: first 5,000 tokens per skill, 25,000 shared. Supporting files are linked from SKILL.md; scripts are run, not loaded; `${CLAUDE_SKILL_DIR}`.
- Commands are merged into skills: `.claude/commands/deploy.md` and `.claude/skills/deploy/SKILL.md` both make `/deploy`; the skill wins on a name clash; every skill gets a `/name`. Args: `$ARGUMENTS`, `$ARGUMENTS[N]` and `$N` are 0-based (`$0` is first), `$name` for named args. Shell injection: `` !`cmd` `` or a fenced block opened with three backticks and `!` (off with `disableSkillShellExecution`). Subfolder namespacing `/frontend:component`; plugin `/plugin-name:skill-name`. `@file` references and `~/.claude/commands` are ND.

## Plugins and marketplaces
- Manifest `.claude-plugin/plugin.json` (optional); only `name` required (kebab-case); `validate` warns without `version`, `description`, `author`. Root folders: `skills/`, `commands/`, `agents/`, `hooks/hooks.json`, `.mcp.json`, `bin/` (added to Bash PATH), `settings.json`, others. `${CLAUDE_PLUGIN_ROOT}` (changes on update), `${CLAUDE_PLUGIN_DATA}` (persists).
- Marketplace `.claude-plugin/marketplace.json`: required `name`, `owner{name}`, `plugins[]`; entry needs `name` and `source`; optional `description`, `version`, `category`, `tags`, `strict` (default true). Sources: `"./plugins/x"`, `{"source":"github","repo":"owner/repo","ref","sha"}`, `{"source":"url","url","ref","sha"}`, `git-subdir`, `npm`, `archive` (`sha256`), `command`. `sha` = full 40-char commit and wins over `ref`.
- CLI: `claude plugin marketplace add <src> [--scope user|project|local]` (local path needs `./`; GitHub `owner/repo[#ref]`; git URL), `marketplace list|update [name]|remove <name>` (remove uninstalls its plugins); `claude plugin install <plugin>@<marketplace> [--scope ...]`, `enable|disable|update|uninstall`, `list`, `details <name>` (component inventory and projected token cost), `validate <path> [--strict] [--json]` (exit 0/1/2), `init <name>`, `eval`. In session: `/plugin ...`, `/reload-plugins`.
- Settings: `extraKnownMarketplaces`, `enabledPlugins` (`"plugin@marketplace": true|false`), `strictKnownMarketplaces` (allowlist; `[]` blocks all), `blockedMarketplaces`, `allowManagedHooksOnly`, `strictPluginOnlyCustomization`.
- Security: a plugin runs arbitrary code as the user; hooks and MCP servers run outside the sandbox; auto-update is on only for official marketplaces.

## Hooks
- Events (blockable marked *): SessionStart, UserPromptSubmit*, PreToolUse*, PermissionRequest (decision object), PostToolUse, PostToolUseFailure, PostToolBatch*, Notification, SubagentStart, SubagentStop*, Stop*, PreCompact*, PostCompact, SessionEnd, plus ConfigChange*, TaskCreated*, TaskCompleted*, InstructionsLoaded and others.
- Handler types: `command`, `http`, `mcp_tool`, `prompt`, `agent`. Shape: `hooks` > Event > `[{matcher, hooks:[{type, command, timeout, shell, if}]}]`. Matcher: `*`/empty = all; plain names or `A|B` exact; otherwise an unanchored JS regex; MCP tools are `mcp__<server>__<tool>`. Hooks merge across user, project, local, managed, plugin and skill/agent frontmatter; matching hooks run in parallel.
- Stdin: `session_id`, `transcript_path`, `cwd`, `permission_mode`, `hook_event_name`; PreToolUse adds `tool_name`, `tool_input`, `tool_use_id`; PostToolUse adds `tool_response`; UserPromptSubmit `prompt`; Stop `stop_hook_active`, `last_assistant_message`; SessionStart `source`.
- Exit 0 = ok (stdout parsed as JSON; plain stdout becomes context on UserPromptSubmit and SessionStart). Exit 2 = block on blockable events, stderr is the reason. Other = non-blocking error. Stop exit-2 behaviour not confirmed: test it.
- JSON out: `continue`, `stopReason`, `systemMessage`, `decision:"block"` + `reason`, `hookSpecificOutput{hookEventName, permissionDecision: allow|deny|ask|defer, permissionDecisionReason, updatedInput, additionalContext}`. Default timeout 600s (30s on UserPromptSubmit).

## Headless and subagents
- `claude -p`; `--output-format text|json|stream-json` (stream-json with `--verbose`); `--max-turns`; `--model` alias or id; `--allowedTools "Bash(git diff *)"`, `--disallowedTools`; `--permission-mode default|acceptEdits|plan|auto|dontAsk|bypassPermissions`; `--append-system-prompt`, `--system-prompt`; `--continue`, `--resume <id>`, `--session-id`; `--mcp-config`, `--strict-mcp-config`; `--settings`, `--setting-sources user,project,local`; `--json-schema` (result has `structured_output`); `--max-budget-usd`; `--fallback-model`; `--bare` (skips hooks, skills, plugins, MCP, memory; needs `ANTHROPIC_API_KEY`). JSON result: `result`, `session_id`, `total_cost_usd`, `usage`; other fields ND, read them from a real run.
- Subagents: `.claude/agents/*.md`, `~/.claude/agents/`, plugin `agents/`, or `--agents '{json}'`. Required `name`, `description`; also `tools`, `disallowedTools`, `model` (sonnet|opus|haiku|inherit|id), `permissionMode`, `maxTurns`, `skills`, `hooks`, `background`, `effort`, `isolation: worktree`. Fresh context window, own system prompt, CLAUDE.md loads, tools inherited; only the final report returns. Nesting up to 3 levels; up to 20 at once. Built-ins: Explore, Plan, general-purpose.

## Telemetry
- Enable: `CLAUDE_CODE_ENABLE_TELEMETRY=1`; `OTEL_METRICS_EXPORTER` and `OTEL_LOGS_EXPORTER` = `console|otlp|none` (metrics also `prometheus`); `OTEL_EXPORTER_OTLP_PROTOCOL` = `grpc|http/json|http/protobuf` (no default); `OTEL_EXPORTER_OTLP_ENDPOINT`; `OTEL_METRIC_EXPORT_INTERVAL` 60000 ms, `OTEL_LOGS_EXPORT_INTERVAL` 5000 ms; `OTEL_LOG_USER_PROMPTS`, `OTEL_LOG_TOOL_DETAILS` off by default; `OTEL_RESOURCE_ATTRIBUTES`.
- Metrics: `claude_code.session.count`, `.token.usage` (`type` = input|output|cacheRead|cacheCreation; `model`, `query_source` = main|subagent|auxiliary), `.cost.usage` (USD), `.lines_of_code.count`, `.commit.count`, `.pull_request.count`, `.code_edit_tool.decision`, `.active_time.total`.
- Events: `claude_code.user_prompt`, `tool_result`, `api_request` (`model`, `cost_usd`, `duration_ms`, `input_tokens`, `output_tokens`, `cache_read_tokens`, `cache_creation_tokens`, `query_source`), `api_error`, `tool_decision`.
