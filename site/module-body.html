Hand this module on

This module is a complete page on its own: briefing, labs, judgment calls and cheat sheet. It names no organization, host, account or internal tool, and every lab runs on plain Claude Code in a scratch folder.

1. The link

When you are reading this on claude.ai, use Share on this page. A viewer needs only the link. Each module has its own link, so you can send one module to one person. Their progress stays in their own browser and is never visible to you.

2. One HTML file

This module is also the single self-contained file {{FILE}}. It needs no server and no network: mail it, put it on a file share, or open it from a USB stick. Offline it falls back to system fonts; everything else is identical, diagrams and instruments included.

3. The whole set

All modules plus the catalogue page (index.html) form one folder of files that link to each other. Keep them together and the links between modules work offline. The same folder works behind any static web server with nothing to configure.

Moving progress between copies

The link, the file and a hosted copy each keep their own progress. Use the progress code on this module's overview to carry it across.
